## 配置

两个 `config.json` 是模型结构说明，不是服务配置。向量模型和精排模型共用同一套 Qwen3 8B 结构，差别在权重和用法：向量模型把句子变成向量，精排模型只看最后一个 token 上 “yes / no” 的概率。

和体积、速度直接相关的字段：

| 字段 | 值 | 作用 |
| --- | --- | --- |
| hidden_size | 4096 | 每层的宽度 |
| num_hidden_layers | 36 | 一共 36 层 |
| num_attention_heads | 32 | 注意力头数 |
| num_key_value_heads | 8 | 键值头更少，这是分组注意力，用来省内存和计算 |
| head_dim | 128 | 每个头的维度，32 × 128 = 4096 |
| intermediate_size | 12288 | 前馈层的中间宽度 |
| max_position_embeddings | 40960 | 最长约 4 万 token |
| vocab_size | 151665 / 151669 | 词表大小。精排模型多几个 token，所以和向量模型不完全相同 |
| torch_dtype | bfloat16 | 权重按 bfloat16 保存，体积大约是 float32 的一半 |
| transformers_version | 4.51.2 / 4.51.3 | 要用这个版本附近的 transformers 才能读懂 Qwen3 |

其余字段是训练时的固定细节：`bos_token_id`、`eos_token_id` 是句子起止符，`rope_theta` 是位置编码的基数，`rms_norm_eps` 是归一化用的小数，`sliding_window: null` 表示没有滑动窗口注意力。

## 命令

服务器没有显卡，所以安装 CPU 版 PyTorch。这台机器上的 Python 3 是 `/opt/miniconda3/bin/python`。如果直接敲 `python3` 提示找不到命令，把下面每条里的 `python3` 换成这个路径。

安装 PyTorch 2.2.2 的 CPU 包。这个版本能在较老的系统上运行，也认得出模型里的 bfloat16 权重。

```bash
python3 -m pip install torch==2.2.2 --index-url https://download.pytorch.org/whl/cpu
```

安装页面和推理依赖。`numpy` 做向量计算，`fastapi` 和 `uvicorn` 提供测试页和 `/eval/qwen` 接口，`transformers==4.51.3` 按上面的 config 加载 Qwen3 并做精排，`sentence-transformers==3.4.1` 把向量模型编码成句向量。清华源只是下载地址。

`sentence-transformers` 会带上图像库 Pillow。这台机器的 gcc 太旧，最新 Pillow 没有二进制包，源码编译会报 `for loop initial declarations are only allowed in C99 mode`。文本推理用不到图像功能，所以固定 `pillow==10.4.0`。PyTorch 2.2 也不能配 NumPy 2，所以固定 `numpy<2`。

```bash
python3 -m pip install "pillow==10.4.0" "numpy<2" "fastapi" "uvicorn" "transformers==4.51.3" "sentence-transformers==3.4.1" -i https://pypi.tuna.tsinghua.edu.cn/simple
```

再装一次 CPU 版 PyTorch。上一条有可能把 PyTorch 换成更新的、带 CUDA 的包，旧系统会装不上或加载失败。

```bash
python3 -m pip install torch==2.2.2 --index-url https://download.pytorch.org/whl/cpu
```

检查安装结果。正常应打印 `2.2.2+cpu False`：版本是 2.2.2 CPU 包，并且没有检测到显卡。

```bash
python3 -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```
